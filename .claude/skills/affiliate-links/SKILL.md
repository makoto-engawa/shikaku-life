# 資格Life アフィリエイトリンク運用スキル

## 大原則（ステマ規制対応・必須）

1. アフィリンクを含むページには**PR表記を必ず入れる**
   - 記事：本文冒頭に `<span class="pr-badge">※当記事にはアフィリエイト広告（PR）が含まれます</span>`
2. アフィリンクの `<a>` には必ず `rel="nofollow sponsored noopener" target="_blank"`
3. 教材の紹介は正直ベースで。デメリット・向かない人も書く（サイトの信頼が最大の資産）

## リンクURLの書き方（重要な現状仕様）

- **記事HTMLには広告主の実URL（af.moshimo.com 等）を直接ハードコードする**
- `/go/<slug>` 経由のリダイレクトは設計上の理想だが、**Render Static 側で `_redirects` が処理されず404になる事象が継続中**（2026-05-27確認）。`/go/` リンクを記事に書いてはいけない
- ただし `_redirects` ファイルは「アフィリンクの台帳」として維持する。**新しい提携URLを記事に入れたら、`_redirects` にも1行追記する**：
  ```
  /go/<slug>  <アフィの実URL>  302
  ```
- 将来 Render 側でリダイレクトが有効化できたら、記事内リンクを `/go/<slug>` に一括置換する（この台帳がその移行リスト）

## 提携先

- **もしもアフィリエイト**：ユーキャン／フォーサイト／スタディング等の資格教材（af.moshimo.com）
- **afb**：一部資格（ピラティス等）
- **Google AdSense**：全ページ `<head>` に ca-pub-2973529127244385 のタグ（消さない）
- 姉妹サイト **ビルメンアカデミー（bilumen.jp）** への送客も収益導線

## リンクを置く場所（記事内の定型）

1. **中間CTA**（`section.mid-cta`）：本文の中盤、「独学が不安なら〜」の3枚カード
2. **末尾教材まとめ**：記事末尾の教材比較・公式サイト誘導
3. **比較ページ**（comparison-*.html）：サイト最大の収益ポイントは `comparison-denko2.html`

## 変更時のチェックリスト

- [ ] PR表記がページ冒頭にあるか
- [ ] `rel="nofollow sponsored noopener"` が付いているか
- [ ] 実URLに計測パラメータ（a_id / p_id 等）が欠けていないか
- [ ] `_redirects` 台帳に追記したか
- [ ] 同じ教材を扱う他ページ（比較ページ・資格個別ページ）にも展開すべきか確認したか
